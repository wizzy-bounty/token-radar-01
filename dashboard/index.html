The old way priced a protocol at its TVL times its category's median multiple. The table below is that model's raw material, kept so the comparison stays honest: the backtest above is run against exactly these medians. The curve's category offset is each category's mean residual from the curve, shrunk by n/(n+15) — a category with three priced tokens moves the fit a fifth as much as its raw residual says.

The curve by size

What the fitted curve pays per dollar of TVL, by the protocol's size — the multiple compression the flat median model cannot express.

Implied value is this radar's own claim about what a launch would be worth if the protocol's record stayed as it is; it is not a prediction that a token will be issued. A protocol here records no token in the snapshot — that is DefiLlama's record, not proof that none exists. Farm plans are written for a reader deciding where to be active before a launch; their costs are the plan's own gas, fees and time, and their verdicts are netted at the low end of each row's value band.
