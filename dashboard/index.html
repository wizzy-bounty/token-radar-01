How to read this board. The house rule ranks protocols with no token recorded once TVL passes the floor; this board lifts the floor, so early protocols are ranked too and the ranked set reconciles exactly with the snapshot. Value if is what the value model says a launch would be worth; implied multiplies that by the odds model's launch probability. Both models are fitted on the snapshot's own protocols and kept only the terms that lowered the miss in all three held-out tests above. The stress verdict reprices each row at its P25 implied value. A FARM verdict is arithmetic at the stated scenario, not a promise that a token will launch.
